# CRK Browser

## Project Introduction

CRK Browser is a modern browser application based on WebView2, developed using C# and WPF, providing rich browsing features and personalized setting options.

### Key Features

- **Multi-tab Browsing**: Support for opening multiple web tabs simultaneously for quick switching
- **Secure Browsing**: Built-in safe site detection to protect your browsing security
- **History Management**: Record and manage your browsing history
- **Bookmark System**: Save and organize your favorite websites
- **User Account**: Support for user login and membership status management
- **Theme Switching**: Offer light blue and dark blue themes
- **Multi-language Support**: Built-in Chinese and English interfaces
- **Personalized Settings**: Rich setting options to meet your personalized needs

## System Requirements

- Windows 10 or Windows 11 operating system
- .NET 8.0 runtime
- WebView2 runtime
- At least 4GB RAM
- At least 100MB available disk space

## Installation Method

1. Get the `CRK-Browser-Setup.exe` installer from the `CRK-Browser.Net/output/` directory
2. Double-click to run the installer
3. Follow the prompts in the installation wizard to complete the installation
4. After installation, a CRK Browser shortcut will appear on your desktop

## Usage Instructions

### Basic Operations

1. **Start the browser**: Double-click the CRK Browser shortcut on your desktop
2. **Open a new tab**: Click the "+" button on the right side of the tab bar
3. **Close a tab**: Click the "×" button on the tab
4. **Navigate**: Enter a URL in the address bar and press Enter
5. **Search**: Enter search keywords in the address bar and press Enter
6. **Forward/Backward**: Use the forward/backward buttons on the toolbar
7. **Refresh**: Use the refresh button on the toolbar
8. **Home**: Use the home button on the toolbar to return to the home page

### Feature Usage

#### Bookmark Management
1. Click the bookmark button on the toolbar
2. In the pop-up bookmark window, you can:
   - Add the current page to bookmarks
   - Browse saved bookmarks
   - Edit or delete existing bookmarks

#### History
1. Click the history button on the toolbar
2. In the pop-up history window, you can:
   - View recent browsing history
   - Filter history by date
   - Clear history

#### Settings
1. Click the settings button on the toolbar
2. In the settings window, you can:
   - **General Settings**: Set home page, search engine, etc.
   - **Privacy Settings**: Manage history, cache, and cookies
   - **Appearance Settings**: Select theme, font size, etc.
   - **Advanced Settings**: Adjust hardware acceleration, developer tools, etc.

#### Language Switching
1. Click the language button on the toolbar
2. Select your preferred language from the drop-down menu (Chinese or English)

#### User Login
1. Click the user button on the toolbar
2. Enter your credentials in the pop-up login window
3. After logging in, you can view your user information and membership status

## Security Features

- **HTTPS Detection**: Automatically detect if websites use secure connections
- **Dangerous Site Warning**: Display warnings when visiting potentially risky websites
- **Data Protection**: Protect your browsing data and personal information

## Frequently Asked Questions

### Q: What should I do if the browser displays "Failed to initialize WebView2 environment" when starting?
A: Please ensure you have installed the latest version of WebView2 runtime. You can download and install it from the Microsoft official website.

### Q: How to clear browsing history?
A: Open the settings window, switch to the "Privacy Settings" tab, then click the "Clear History" button.

### Q: How to change the browser theme?
A: Open the settings window, switch to the "Appearance Settings" tab, then select your preferred theme from the "Theme" drop-down menu.

### Q: How to add a website to bookmarks?
A: Navigate to the website you want to add, then click the bookmark button on the toolbar, and click the "Add Bookmark" button in the pop-up window.
